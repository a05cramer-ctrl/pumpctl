01Install

One command. No build step.

Node 20+. npx runs it directly. Use a burner wallet that only holds what you're willing to lose — or leave the key out for read-only mode.

terminal
claude mcp add pumpctl \
  -e PUMPCTL_PRIVATE_KEY=<burner key> \
  -e SOLANA_RPC_URL=<rpc> \
  -e PUMPCTL_MAX_SOL_PER_TRADE=0.5 \
  -- npx -y pumpctl-mcp

Then run /mcp inside Claude Code — pumpctl shows up with 7 tools.

.cursor/mcp.json

          

        

        
Per project in .cursor/mcp.json, or globally in ~/.cursor/mcp.json.

      


      

        
PUMPCTL_PRIVATE_KEY
Burner wallet secret (base58 or JSON byte array). Unset = read-only.

        
SOLANA_RPC_URL
Your RPC for balances and sending. Helius, Triton, QuickNode.

        
PUMPCTL_MAX_SOL_PER_TRADE
Hard cap per buy or dev buy. Default 0.5. Above it: refused.

        
PUMPCTL_MAX_PRIORITY_FEE
Hard cap on priority fee per transaction. Default 0.01 SOL.

      

    

  


  

    

      
02Tools

      
Seven tools. Four read, three write.

      
Reads stream straight from PumpPortal, DexScreener and your RPC. Writes return a dry run unless called with confirm: true.

    

    

  


  

    

      
03Safety

      
Your key signs here.
Nowhere else.

      
PumpPortal only builds the unsigned transaction. pumpctl checks it, signs it in-process on your machine, and sends it to your RPC.

    


    

    
    
      
  1. 01
    Key stays local
    Used in-process to sign. Never sent to PumpPortal, pump.fun or anyone. Never logged, never returned by a tool.
    2. 
      
  2. 02
    Dry run by default
    pump_buy, pump_sell and pump_launch return exactly what would be sent — and make no network call — unless confirm: true.
    3. 
      
  3. 03
    Hard caps
    Buys above PUMPCTL_MAX_SOL_PER_TRADE (default 0.5) and priority fees above the fee cap are refused, confirmed or not.
    4. 
      
  4. 04
    Read-only mode
    No key configured? Every read tool works. Write tools explain how to enable trading and do nothing else.
    5. 
      
  5. 05
    Fee-payer check
    Before signing, pumpctl refuses any transaction whose fee payer isn't your wallet or that asks for an unexpected signer.
    6. 
      
  6. !!
    Real money
    Memecoins go to zero. Use a fresh burner wallet, and keep tool approval on for the three write tools in your MCP client.
